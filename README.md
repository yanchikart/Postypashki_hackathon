# Postupashki Marketing Measurement System (MMS)

End-to-end система сквозного учёта Telegram-маркетинга, инкрементального ROMI и оптимизации рекламного бюджета для онлайн-школы «Поступашки».

## Быстрый старт (Воспроизводимость)

### 1. Установка зависимостей
```bash
pip install pandas openpyxl numpy
```

### 2. Запуск аналитического пайплайна
```bash
python pipeline.py
```
* Пересчитывает сквозную атрибуцию (окно 21 день) и органический Baseline (54 482.50 ₽/день).
* Проводит сравнение 4 моделей атрибуции (Last Touch, First Touch, Linear, Time Decay).
* Выполняет Backtest прогноза дневной выручки (Naive Baseline vs Factor Model).
* Генерирует `marketing_measurement_system.xlsx` и `metrics.json`.

### 3. Запуск локального API и Mini App
```bash
python server.py
```
Откройте браузер по адресу: `http://localhost:8000`.

## Разделение данных (Data Provenance)

* **Реальные данные (Real Data):**
  * `orders.csv`: 628 уникальных заказов от 606 студентов (153 комплексных бандла), агрегированных из `base.xlsx`.
  * `posts.csv`: 45 реальных публикаций из `tg_posts_export.xlsx` с охватами, реакциями и репостами.
* **Синтетические данные (Mock / Synthetic):**
  * `leads.csv`: симуляция журнала переходов по deep-link ссылкам (70% сопоставленных пользователей, 30% органики) для калибровки 21-дневного окна атрибуции до запуска боевого Telegram-бота.

## Ответ на бизнес-вопрос: «Куда вложить 300 000 ₽?»

На основе предельной инкрементальной отдачи ($Incremental\ Revenue / Budget$) система рекомендует следующий сплит:

1. **BigTech стажировки (130 000 ₽ / 43.3%):** мультипликатор x17.77. Максимальный отклик на внешние дедлайны без демпинга.
2. **Флагманы ПРО и AI (90 000 ₽ / 30.0%):** мультипликатор x8.62. Формирует основную валовую кассу за счёт чека 9 967 ₽.
3. **Распродажа СТАРТ -55% (45 000 ₽ / 15.0%):** мультипликатор x18.41. Искусственно ограничена суммой 45-60k ₽ для предотвращения каннибализации полной цены.
4. **Лид-магниты NoSQL (25 000 ₽ / 8.3%):** подпитка базы новыми контактами в Mini App.
5. **Внешние посевы (10 000 ₽ / 3.4%):** тестирование ёмкости новых каналов.

**Итоговый прогноз:** +5.48 млн ₽ инкрементальной выручки и **+3.42 млн ₽ чистой прибыли**.
